> **Stop Pushing Against What Won’t Move. S.L.I.D.E. Into What’s Next.**

## ✦ Design System & Technology Stack

- **Markup:** Semantic HTML5 (SEO optimized with OpenGraph and Twitter Card metadata).
- **Styling:** **Tailwind CSS v3** via CDN with custom color tokens + `css/custom.css` for custom keyframe animations and glassmorphism.
- **Color Palette:**
  - Backgrounds: Warm Obsidian & Charcoal (`#090a0d`, `#11131b`, `#141720`)
  - Metallic Accents: Champagne Gold & Warm Amber (`#d4af37`, `#fef08a`, `#e5c158`, `#aa820a`)
  - Accent Contrast: Deep Rose/Crimson (`#f43f5e`, `#9f1239`) for gridlock indicators
- **Typography:**
  - Display / Serif Headlines: `Instrument Serif` (Google Fonts)
  - Body / UI: `Plus Jakarta Sans` (Google Fonts)
- **Scripting:** Pure Vanilla ES6 JavaScript (Zero heavy external dependencies; 60fps performance).

## ✦ Local Development & Preview

No build steps or complex installations required.

### Method 1: Python HTTP Server
```bash
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Method 2: Node.js / npx
```bash
npx serve
```

### Method 3: VS Code Live Server
Right-click `index.html` and choose **"Open with Live Server"**.

## ✦ Deployment

This project is 100% static and can be deployed instantly to:
- **GitHub Pages:** Settings > Pages > Select `main` branch.
- **Vercel:** Run `vercel` in the project root.
- **Netlify:** Drag and drop the directory into Netlify.
