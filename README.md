## ✦ Design System & Technology Stack

- **Markup:** Semantic HTML5 (SEO & OpenGraph optimized).
- **Styling:** **Tailwind CSS v3** via CDN with custom color tokens + `css/custom.css`.
- **Palette:** Warm Obsidian (`#090a0d`), Champagne Gold (`#d4af37`), Vibrant Brush Orange (`#f97316`, `#ff6b00`), Royal Blue (`#2563eb`), and Electric Violet (`#a855f7`).
- **Typography:** `Instrument Serif` (Headlines) & `Plus Jakarta Sans` (Body & UI).
- **Scripting:** Pure Vanilla ES6 JavaScript (Zero heavy external dependencies; 60fps performance).
